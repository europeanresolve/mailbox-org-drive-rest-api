Choices made here under CONTEXT.md "Claude's Discretion":
- Summary for an array of objects: `COUNTIF('<sheet>'!$A$<first>:$A$<last>,A<row>)`, the item count, using a function verified in OX; the criterion is the main sheet's own id cell, a reference, not an embedded value. The same COUNTIF is used for an array of arrays (its outer sheet has id and index only) and for an array of date items (TEXTJOIN would show date serial numbers).
- Uniform rule for non-scalar items: the array gets an outer sheet with id, index and the item's flattened scalar fields; every array nested inside its items gets one sheet per outer element index, recursively (`systems(0).planets(2).moons`). Summary formulas exist only on the main sheet (D-11); outer and element sheets have no columns for their nested arrays.
- Cell ranges use column C (value) for scalar arrays and column A (id) for COUNTIF; rows are 1-based with row 1 the header, so a record's first item is at row 2 or later.
- Sheet references are always single-quoted; plan 03-06 guarantees no `'` in property names, so no escaping is needed, and quoted names with `.` and `(0)` were verified in OX.
- The suffix rule is stable through the fixed naming order (the user accepted "deterministic order of fields" as the stability mechanism in discussion). The main sheet name from D-24 is reserved first. Comparison is case-insensitive because Excel treats sheet names that way, and `History` is reserved by Excel.
- Sheet cap 255 per workbook (main and top-level array sheets come first, so only element sheets can be omitted).
</context>
